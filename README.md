# 온기 카페 랜딩 페이지

동네 카페 "온기 카페"를 소개하는 간단한 한 페이지짜리 웹사이트입니다.
HTML과 CSS만으로 만들었고, 별도 설치나 빌드 없이 바로 열어 볼 수 있습니다.

## 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 페이지 내용 (대표 메뉴, 카페 소개, 찾아오시는 길) |
| `style.css` | 디자인 (색상, 배치, 모바일 대응) |

## 보는 방법

`index.html` 파일을 더블클릭하면 브라우저에서 열립니다.

## 고치는 방법

- 메뉴 이름과 가격: `index.html`의 `#menu` 부분
- 주소와 영업시간: `index.html`의 `#visit` 부분 (현재 주소는 예시입니다)
- 색상: `style.css`의 `background`, `color` 값
